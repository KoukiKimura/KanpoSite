## 1. 必須機能以外に必要と思われる機能提案

要件定義書に定めた必須機能に加え、ブランドサイトとして競争力を高め、ユーザー体験を向上させるために以下の機能追加を提案する。

| 機能名 | 提案理由 | 優先度 | フェーズ |
|---|---|---|---|
| ブログ・読み物コンテンツ | SEO集客・ブランド教育・リピート訪問促進 | 高 | フェーズ2 |
| メルマガ登録フォーム | リピーター育成・新商品告知 | 高 | フェーズ2 |
| 商品レビュー・口コミ | 購入意思決定の後押し・信頼構築 | 中 | フェーズ2 |
| お気に入り（ウィッシュリスト） | 後日購入促進・ユーザーエンゲージメント向上 | 中 | フェーズ2 |
| クーポン・割引コード | 初回購入・SNS誘導・メルマガ特典 | 中 | フェーズ2 |
| 在庫通知（入荷通知） | 機会損失を防ぐ | 中 | フェーズ2 |

| ポイント・スタンプ制度 | リピーター育成 | 低 | フェーズ3 |
| ギフトラッピング対応 | 贈答需要への対応 | 中 | フェーズ2 |

## 2. EC に必要な補助機能提案

### 2.1 在庫管理

- **提案**: 管理画面またはスプレッドシート連携での在庫数管理
- **候補ツール**: 
  - Shopify（EC全体を委託する場合）
  - 自作APIサーバー + 管理画面（Next.js + Prisma + PlanetScale 等）
  - Google Sheets API 連携（小規模な場合の簡易策）
- **考慮点**: 在庫切れ時の自動メール通知・入荷待ちリスト機能

### 2.2 配送管理

- **提案**: 配送業者API連携（ヤマト運輸・佐川急便等）
- **実装案**: 発送時に追跡番号をメールで通知
- **送料設計**:

  | 条件 | 送料（目安） |
  |---|---|
  | 〜¥5,999 | ¥600（全国一律） |
  | ¥6,000以上 | 送料無料 |
  | 北海道・沖縄・離島 | 追加送料 ¥300〜 |

### 2.3 レビュー機能

- **提案**: 購入者限定のレビュー投稿（星5段階 + テキスト）
- **実装候補**:
  - Stamped.io（Shopify連携）
  - 自作（購入確認メールからのレビュー投稿リンク）
- **注意**: 不正レビュー防止のため購入確認が必要

### 2.4 クーポン機能

| クーポン種別 | 用途 |
|---|---|
| 初回購入割引 | 新規顧客獲得 |
| メルマガ登録特典 | メルマガ購読者獲得 |
| 誕生日クーポン | リピーター育成 |
| SNS拡散クーポン | SNS口コミ促進 |
| セット割引 | 客単価向上 |

## 3. ブランドサイトとしての訴求強化案

### 3.1 ブログ・読み物コンテンツ

- **目的**: SEO集客・ブランド教育・ユーザーエンゲージメント向上
- **コンテンツ案**:

  | カテゴリ | 記事テーマ例 |
  |---|---|
  | 薬草知識 | 「クコの実の効能と漢方での使い方」 |
  | 季節の養生 | 「秋の乾燥対策に効く薬草5選」 |
  | レシピ | 「薬草茶のブレンドレシピ」 |
  | 畑だより | 「今月の畑の様子・収穫報告」 |
  | コラム | 「漢方と現代生活の接点」 |

- **SEO効果**: 薬草・漢方関連のロングテールキーワードで自然検索流入を獲得

### 3.2 動画コンテンツ活用

- **提案**: 畑の様子・加工工程・ブランドストーリーの動画をYouTube公開 → サイトに埋め込み
- **効果**: 滞在時間向上・ブランド信頼性強化

### 3.3 Before/After・使用感ギャラリー

- **提案**: 顧客の使用感・感想を写真付きで掲載（許可取得の上）
- **効果**: 購入後のイメージ訴求・レビューの代替として機能

## 4. ゲストハウス導線の改善案

### 4.1 現状の課題と改善提案

| 課題 | 改善案 |
|---|---|
| 予約が外部リンクのみで完結しない | フェーズ2で独自予約フォーム実装 |
| 体験内容が伝わりにくい | 体験プログラムの動画・写真を充実させる |
| 口コミが少ない | Googleマップ・じゃらんレビューへの誘導 |
| リピーターへの特典がない | 宿泊者向けクーポン（EC割引）の発行 |

### 4.2 宿泊×EC のクロスセル

- 宿泊者に「畑で使用している薬草商品」の特別セットを紹介
- ゲストハウス到着時にウェルカムドリンク（自社薬草茶）を提供 → ECへ誘導
- 宿泊後フォローメールに商品案内を含める

### 4.3 Facebook 活用戦略

- Facebook ページで宿泊体験の日常的な発信を行う
- Instagram との連携で若年層にもリーチ
- Facebook イベント機能で薬草収穫体験・茶会の告知

## 5. 運用を楽にするための提案

### 5.1 Headless CMS 導入提案

コンテンツ更新（商品・ブログ・お知らせ等）を非エンジニアが管理できるよう、Headless CMS の導入を推奨する。

#### 主要候補の比較

| CMS | 料金 | 特徴 | おすすめ度 |
|---|---|---|---|
| **microCMS** | 無料〜（Hobbyプラン無料） | 日本語UI・日本製・サポート充実 | ⭐⭐⭐⭐⭐ |
| **Contentful** | 無料〜（Communityプラン） | 国際標準・機能豊富・英語UI | ⭐⭐⭐⭐ |
| **Sanity** | 無料〜（Freeプラン） | 柔軟なスキーマ・リアルタイムコラボ | ⭐⭐⭐⭐ |
| **Newt** | 無料〜 | 日本製・シンプルUI | ⭐⭐⭐ |
| **WordPress（Headless）** | 無料（サーバー代のみ） | 既存知識が活かせる | ⭐⭐⭐ |

**推奨**: **microCMS**（日本語対応・クライアントが使いやすい・Next.js連携が豊富）

### 5.2 お知らせ・ブログ更新フロー

```
microCMS 管理画面 → 記事更新 → GitHub Actions Webhook → Vercel/ConoHa 再ビルド
```

ConoHa WING の場合：GitHub Actions で静的ファイルをFTP転送するビルドパイプラインを構築。

### 5.3 商品管理フロー（簡易EC）

- 商品情報（名前・価格・説明・画像）は microCMS で管理
- 在庫管理は Google Sheets API または簡易管理画面で対応
- 注文管理は決済サービス（Stripe）のダッシュボードで管理

## 8. EC 機能実装候補の比較

### 8.1 決済サービス比較

| サービス | 手数料 | 特徴 | おすすめ度 |
|---|---|---|---|
| **Stripe** | 3.6% | API充実・国際対応・Webhook豊富・Next.js連携が容易 | ⭐⭐⭐⭐⭐ |
| **Square** | 3.6% | 実店舗との連携・レジアプリとの統合 | ⭐⭐⭐⭐ |
| **PAY.JP** | 3.0〜 | 国内特化・日本語サポート充実 | ⭐⭐⭐⭐ |
| **GMO PG** | 要見積 | 大規模EC向け・法人向け | ⭐⭐⭐ |
| **PayPay for Business** | 1.98〜 | 国内QRコード決済・若年層向け | ⭐⭐⭐ |

**推奨**: **Stripe**（開発の容易さ・ドキュメントの充実・Next.js公式サポート）

### 8.2 Shopify 採用可否の検討

Shopify をEC全体のバックエンドとして使い、フロントエンドをNext.jsで構築する「Shopify Headless」も選択肢。

| 項目 | カスタムEC（Next.js + Stripe） | Shopify Headless |
|---|---|---|
| 初期コスト | 低（開発工数のみ） | 月額$29〜 + 開発工数 |
| 在庫管理 | 要自作 | Shopify管理画面で完結 |
| 決済 | Stripe/Squareを選択 | Shopify Payments（2.0%） |
| 拡張性 | 自由度高い | Shopifyエコシステムに依存 |
| 運用難易度 | やや高 | 低い（管理画面が使いやすい） |
| 推奨ケース | 商品数少・こだわりUX | 商品数多・非エンジニアが運用 |

**現時点の推奨**: 商品数が少ない初期段階では **Next.js + Stripe のカスタムEC** を採用し、商品数増加・運用負担増加の場合は Shopify Headless への移行を検討する。
