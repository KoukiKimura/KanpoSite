## 7. ページごとの SEO 検討項目

### 7.1 トップページ（/）

- [ ] `<h1>` タグを1つだけ使用し、ブランド名 + 主要キーワードを含める
- [ ] 主要キーワード: 「漢方」「薬草」「○○（地域名）」「オンラインショップ」
- [ ] ヒーロー画像に適切な `alt` を設定する
- [ ] ページの読み込み速度を最適化する（画像の WebP 変換・遅延読み込み）

### 7.2 商品一覧ページ（/products）

- [ ] `<h1>` に「漢方商品一覧」等のキーワードを含める
- [ ] カテゴリページの `<title>` をカテゴリ名を含む形にする
- [ ] カテゴリごとに個別URLを持たせ、インデックスさせる
- [ ] ページネーションに `rel="next"` / `rel="prev"` を設定する（または `link canonical`）

### 7.3 商品詳細ページ（/products/[slug]）

- [ ] `<h1>` に商品名を設定する
- [ ] 商品説明文は500文字以上を目標にする
- [ ] 商品名・成分・用途等のキーワードを自然に本文に含める
- [ ] 商品画像のファイル名・alt属性を最適化する
- [ ] `Product` 構造化データを実装する（→ 4-3）

### 7.4 ブランド紹介ページ（/brand）

- [ ] `<h1>` に「ブランド名 について」等を設定する
- [ ] ブランドストーリーに「漢方」「薬草」「自然農法」等のキーワードを自然に含める
- [ ] E-E-A-T（経験・専門性・権威性・信頼性）を高めるコンテンツを作成する

### 7.5 畑紹介ページ（/farm）

- [ ] 農場の地域名・特徴をキーワードに含める
- [ ] 薬草の種類名（和名・学名）をテキストに含める
- [ ] Local Business スキーマを設定する（→ 4-7）

### 7.6 ゲストハウス紹介ページ（/guesthouse）

- [ ] 「農家民宿」「薬草体験」「ゲストハウス ○○（地域名）」等のキーワードを含める
- [ ] Local Business スキーマを設定する（→ 4-7）
- [ ] Google マイビジネスへの登録・連携を確認する

### 7.7 ブログ記事（/blog/[slug]）（フェーズ2）

- [ ] 記事ごとにターゲットキーワードを1つ決める
- [ ] `<h1>` にキーワードを自然に含める
- [ ] 記事内の見出し（h2/h3）にもサブキーワードを含める
- [ ] 内部リンクを記事内に2〜3個含める
- [ ] `Article` 構造化データを実装する（→ 4-9）
