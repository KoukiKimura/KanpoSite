## ディレクトリ構成

| ディレクトリ | 内容 |
|---|---|
| README.md | docs 配下の管理ルール |
| ロードマップ/ | 開発ロードマップ・web_mockロードマップ |
| 要件定義/ | サイト要件定義書などの要件定義ドキュメント |

## ルール

- docs/ 直下には README.md と横断資料のみを置く。ロードマップは `ロードマップ/`、要件定義は `要件定義/`、設計書は `サイト設計/` に配置する
- ファイル名は日本語を基本とし、README や技術識別子を含む名称は例外とする
- 正規方針はShopify案とし、採用しない案は `archive/` 配下で管理する
