## 2. 修正した軽微事項

| 指摘 | 反映 |
|---|---|
| `contact-api/public/contact.php` と公開URL `/contact-api/contact.php` の対応が読み取りにくかった | `public/contact.php` はデプロイ時に `contact-api/` の公開入口へ配置し、`src/`、`config/`、`var/` は公開Webルート外に置く方針を明記 |
| Notion記事の `RelatedProductSlugs` がShopify handleとして解決できない場合の扱いが「警告またはエラー」で曖昧だった | Published記事では警告ログを出し、該当商品の関連商品表示から除外する方針へ明確化 |
| 再レビュー後の状態がメタ情報に反映されていなかった | バージョンを 1.0.1、ステータスを再レビュー済みに更新 |
