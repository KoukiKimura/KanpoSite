## 1. プロジェクト概要

### 1.1 プロジェクト名

漢方ブランド 公式サイト（KanpoSite）

### 1.2 プロジェクト背景

日本の伝統的な漢方・薬草文化を現代に伝えるブランドとして、国内外に向けて商品・価値観・ライフスタイルを発信するためのブランドサイトを構築する。単なるECサイトにとどまらず、畑・栽培環境・ゲストハウスなどの体験価値も含めた総合的なブランドプラットフォームを目指す。

### 1.3 プロジェクト目的

- 漢方商品のオンライン販売（EC機能）を実現する
- ブランドのストーリー・理念・こだわりを国内外のユーザーに伝える
- 畑・農場の様子を可視化し、原材料へのこだわりを訴求する
- ゲストハウスの認知向上と宿泊・体験申込みへの導線を構築する
- SNS（Facebook等）との連携でリアルな情報発信を補完する
- 将来的な多言語対応（英語・中国語等）の基盤を整える

### 1.4 対象サイトURL（予定）

- 本番: https://（ドメイン未定）
- ホスティング: ConoHa WING

## 2. 想定ユーザー（ターゲット）

### 2.1 メインターゲット

| ターゲット区分 | 詳細 |
|---|---|
| 国内・健康意識の高い30〜60代女性 | 漢方・薬草・自然療法に関心があり、食や生活にこだわりを持つ層 |
| 国内・贈答需要層 | 両親・友人への贈り物として自然派・国産ブランド品を探している層 |
| 農業・ハーブ・薬草に関心のある若年層 | 農的暮らし・薬草文化に興味を持ち、体験・学びを求める20〜40代 |
| インバウンド・海外在住日本人 | 日本の伝統薬草文化に関心のある外国人・海外在住の日本人 |

### 2.2 サブターゲット

- 飲食業・薬局・サロン等のB2B購入者
- ゲストハウス宿泊・農業体験を求める旅行者

### 2.3 ユーザーの主な課題・ニーズ

- 信頼できる国産・自然由来の漢方商品を探している
- 商品の原材料や栽培環境について詳しく知りたい
- ブランドのこだわりや背景を理解した上で購入したい
- 体験型観光・ファームステイに関心がある

## 4. 必須機能

### 4.1 トップページ機能

- ファーストビュー：ブランドイメージを伝えるフルスクリーン or 大判ビジュアル
- キャッチコピー・ブランドメッセージの掲載
- 注目商品・新着商品のピックアップ表示（最大6点）
- 各主要ページへの導線バナー（畑・ゲストハウス・ブランド紹介）
- お知らせ・新着情報セクション（最新3〜5件）
- Instagram or Facebook フィード埋め込み（SNS連携）
- グローバルナビゲーション（全ページ共通）

### 4.2 商品販売機能（EC）

#### 商品一覧

- カテゴリ別フィルタリング（茶・チンキ・粉末・ドライハーブ 等）
- 商品カード表示（商品名・価格・サムネイル画像・在庫状態）
- ページネーション or 無限スクロール
- 並び順変更（新着順・価格順・人気順）

#### 商品詳細

- 商品名・価格・説明文・成分表示
- 複数商品画像のギャラリー表示
- 使用方法・注意事項の掲載
- 数量選択・カートに追加ボタン
- 関連商品の表示（最大4点）

#### カート・購入

- カート内容の表示・数量変更・削除
- 配送先入力フォーム
- 決済連携（Stripe または Square）
- 注文確認メールの自動送信
- 送料計算（金額・地域別）
- 在庫チェック（在庫切れ表示）

### 4.3 ブランド紹介機能

- 代表メッセージ（写真＋テキスト）
- ブランドの歴史・沿革タイムライン
- こだわり・ストーリーの詳細テキスト
- スタッフ紹介（任意）
- 受賞歴・メディア掲載実績（任意）

### 4.4 畑紹介機能

- 畑・農場の紹介文と写真ギャラリー
- 栽培している薬草・植物の種類一覧
- 季節ごとの畑の様子（フォトエッセイ形式）
- 農薬不使用・有機農法等のこだわり表示
- 地図・所在地の表示（Google Maps 埋め込み）

### 4.5 ゲストハウス紹介機能

- 施設概要・外観・室内写真ギャラリー
- 宿泊プラン・料金案内
- Facebook ページへのリンク・埋め込みプレースホルダー
- アクセス情報・地図（Google Maps 埋め込み）
- 予約への導線（外部予約サービスへのリンク、または将来的な予約フォーム）
- 体験プログラム一覧（薬草収穫体験・茶会等）

### 4.6 共通機能

- レスポンシブデザイン（モバイルファースト）
- グローバルナビゲーション（ロゴ・主要ページリンク・カートアイコン）
- フッター（サイトマップリンク・SNSリンク・法的表記リンク・コピーライト）
- パンくずリスト（商品詳細・各下層ページ）
- 404エラーページ
- お問い合わせフォーム（reCAPTCHA対応）
- SEO基本設定（メタタグ・OGP・JSON-LD）

## 6. 非機能要件

### 6.1 パフォーマンス要件

| 項目 | 目標値 |
|---|---|
| ページ読み込み速度（LCP） | 2.5秒以内（Core Web Vitals 良好範囲） |
| First Contentful Paint（FCP） | 1.8秒以内 |
| Cumulative Layout Shift（CLS） | 0.1以下 |
| Lighthouse スコア（パフォーマンス） | 85点以上 |
| Lighthouse スコア（SEO） | 95点以上 |

### 6.2 セキュリティ要件

- HTTPS 常時SSL（ConoHa WING の無料SSL利用）
- フォーム送信には reCAPTCHA v3 を適用
- 個人情報（氏名・住所・メールアドレス等）はサーバーに直接保存せず、決済は外部決済サービスに委託
- 環境変数（APIキー等）はリポジトリにコミットしない（.env管理）
- 依存パッケージの定期的なセキュリティアップデート

### 6.3 SEO要件

- 全ページにメタタイトル・メタディスクリプション設定
- OGP（Open Graph Protocol）タグの設定
- 構造化データ（JSON-LD）の実装（商品・組織・パンくず）
- サイトマップ（sitemap.xml）の自動生成
- robots.txt の適切な設定
- 画像のalt属性を全て設定
- Core Web Vitals の継続的な計測・改善

### 6.4 アクセシビリティ要件

- WCAG 2.1 AA 準拠を目標とする
- キーボードナビゲーション対応
- スクリーンリーダー対応（aria-label等の適切な設定）
- カラーコントラスト比 4.5:1 以上（テキスト）
- フォーム要素への適切なラベル付け
- 画像への alt テキスト設定

### 6.5 ブラウザ・デバイス対応

| 対象 | 詳細 |
|---|---|
| モバイル | iOS Safari / Android Chrome（最新2バージョン） |
| PC ブラウザ | Chrome / Firefox / Safari / Edge（最新2バージョン） |
| 画面サイズ | 375px（SP最小）〜 1920px（PC最大） |

### 6.6 ホスティング・インフラ要件

- ホスティング: ConoHa WING（静的エクスポート or Node.js 対応プラン）
- フレームワーク: Next.js（Static Export または SSR）
- バックアップ: 月次でのファイル・DB バックアップ
- 稼働率目標: 99.5% 以上（ConoHa WING SLA 準拠）

## 7. 制約・前提条件

- 初期リリースはフェーズ1（必須機能のみ）での公開を目指す
- ゲストハウスの宿泊予約は初期リリースでは外部サービスへのリンクで対応
- 決済は Stripe または Square を利用し、PCI DSS 準拠を外部に委ねる
- コンテンツ（商品写真・説明文等）は別途クライアントから提供を受ける
- SNS（Facebook）のページURLは後日確定・差し替え予定
