# 改修前バックアップ手順書

**対象:** 大規模改修・テーマ更新・セクション追加・デザイン変更等を行う前  
**目的:** お客様が管理画面で行った変更のデグレ防止・商品データ消失防止

---

## 管理画面から変更できる情報の一覧

Shopify 管理画面では、以下の情報をお客様が随時変更できます。改修前には全て取得する必要があります。

### テーマ・デザイン系（`theme pull` で取得）

| 対象 | 場所 | 変更内容の例 |
|---|---|---|
| セクション設定 | テーマエディタ → 各セクション | テキスト・画像・表示 ON/OFF |
| テーマ全体設定 | テーマエディタ → テーマ設定 | カラー・フォント・余白設定 |
| テンプレートレイアウト | テーマエディタ → ページ | セクションの追加・並び替え |
| カスタム CSS | テーマエディタ → CSS | スタイルの微調整 |

> `settings_data.json` に全設定値が記録されます。

### データ系（`backup-shopify.mjs` で取得）

| 対象 | 保存ファイル | 変更内容の例 |
|---|---|---|
| ショップ基本情報 | `shop.json` | 店舗名・メール・電話番号・住所・通貨・タイムゾーン |
| 商品 | `products.json` / `products.csv` | 商品名・価格・在庫・説明・タグ |
| 商品バリアント | products に含む | サイズ・カラー・SKU |
| 商品メタフィールド | products に含む | 内容量・原材料・飲み方・注意事項 |
| 商品画像 | products に含む | alt テキスト・画像順序 |
| コレクション | `collections.json` | コレクション名・説明・商品の並び順 |
| 固定ページ | `pages.json` | ページ本文・SEO 設定 |
| ブログ記事 | `blogs.json` | 記事本文・タグ・アイキャッチ |
| ナビゲーション | `menus.json` | ヘッダー・フッターのリンク構成 |
| ポリシーページ | `policies.json` | 返品・プライバシー・利用規約・配送 |
| URL リダイレクト | `redirects.json` | 旧 URL → 新 URL の転送設定 |
| メタフィールド定義 | `metafield-definitions.json` | カスタムフィールドの定義 |
| メタオブジェクト定義 | `metaobject-definitions.json` | FAQ・特集コンテンツ等のスキーマ定義 |
| メタオブジェクトデータ | `metaobject-instances.json` | FAQの内容・特集コンテンツの実データ |
| アップロードファイル | `files.json` | 管理画面からアップロードした画像・PDFのURL一覧 |
| マーケット | `markets.json` | 国・地域・通貨設定 |
| 配送ゾーン・送料 | `shipping-zones.json` | 配送先地域・送料・無料配送条件 |
| ロケーション | `locations.json` | 在庫管理場所（倉庫・店舗） |
| Script Tags | `script-tags.json` | 外部スクリプト（Google Analytics・GTM 等）|
| 通知メールテンプレート | `notifications.json` | 注文確認・発送通知メールの文言 |
| 割引・価格ルール | `discounts.json` | クーポンコード・セール・自動割引 |
| テーマ一覧 | `themes.json` | ライブテーマ・控えテーマのID一覧 |

> **取得できないもの（管理画面のみ）:** 決済ゲートウェイの詳細設定、Shopify Payments の銀行口座情報、税設定の詳細。これらはテーマ改修で変更されることはなく、APIアクセス権限外のため手動確認が必要です。

## 改修前の作業フロー

### ステップ 1: 最新テーマをローカルに取得

```powershell
cd web_shopify
shopify theme pull --theme 154692485277
```

> テーマエディタで変更された `settings_data.json` が取り込まれます。

### ステップ 2: データバックアップを取得

```powershell
# 検証環境
node scripts/backup-shopify.mjs

# 本番環境
node scripts/backup-shopify.mjs --env=production
```

`web_shopify/backup/` に以下が保存されます:
- `shop.json`
- `products.json` / `products.csv`
- `collections.json`
- `pages.json`
- `blogs.json`
- `menus.json`
- `policies.json`
- `redirects.json`
- `metafield-definitions.json`
- `metaobject-definitions.json`
- `metaobject-instances.json`
- `files.json`
- `shipping-zones.json`
- `locations.json`
- `script-tags.json`
- `notifications.json`
- `discounts.json`
- `themes.json`
- `manifest.json`（取得日時・ストア情報）

### ステップ 3: Git にコミット（スナップショット）

```powershell
git add web_shopify/
git commit -m "backup: 改修前スナップショット $(Get-Date -Format 'yyyy-MM-dd')"
```

これにより、改修前の状態がバージョン管理に記録されます。

### ステップ 4: 改修作業

通常通りテーマファイルを編集します。

### ステップ 5: 改修後のプッシュ

```powershell
shopify theme push --theme 154692485277
```

## データ系のデグレ・消失について

| 操作 | 商品データへの影響 |
|---|---|
| `theme push` | **影響なし**（テーマのみ更新。商品・注文・顧客は変更されない）|
| `seed-shopify.mjs` | **既存データを上書きする可能性あり**（バックアップ後に実行すること）|
| `backup-shopify.mjs` | 読み取りのみ。データは変更しない |

> `theme push/pull` は商品・注文・顧客データに **一切影響しません**。

---

## 万が一の復旧手順

### テーマ設定のロールバック

Git の過去コミットから `settings_data.json` を取り出してプッシュします:

```powershell
git show HEAD~1:web_shopify/config/settings_data.json > config/settings_data.json
shopify theme push --only config/settings_data.json --theme 154692485277
```

### 商品データの復元

管理画面で CSV インポートが可能です:

> **管理画面 → 商品管理 → インポート → `products.csv` を選択**

JSON バックアップから `seed-shopify.mjs` を修正して再投入することも可能です。

## バックアップファイルの保存場所

```
web_shopify/
└── backup/
    ├── README.md                    # このドキュメント
    ├── manifest.json                # 取得日時・環境情報
    ├── shop.json                    # ショップ基本情報
    ├── products.json                # 商品情報（完全）
    ├── products.csv                 # 商品情報 CSV（再インポート用）
    ├── collections.json             # コレクション
    ├── pages.json                   # 固定ページ
    ├── blogs.json                   # ブログ・記事
    ├── menus.json                   # ナビゲーション
    ├── policies.json                # ポリシーページ
    ├── redirects.json               # URL リダイレクト
    ├── metafield-definitions.json   # メタフィールド定義
    ├── metaobject-definitions.json  # メタオブジェクトスキーマ定義
    ├── metaobject-instances.json    # メタオブジェクトデータ（FAQ等実コンテンツ）
    ├── files.json                   # アップロードファイル一覧（画像・PDF）
    ├── shipping-zones.json          # 配送ゾーン・送料設定
    ├── markets.json                 # マーケット（国・地域・通貨）
    ├── locations.json               # ロケーション（在庫管理場所）
    ├── script-tags.json             # Script Tags（外部スクリプト）
    ├── notifications.json           # 通知メールテンプレート
    ├── discounts.json               # 割引・価格ルール・クーポン
    └── themes.json                  # テーマ一覧（ライブ/控え）
```
