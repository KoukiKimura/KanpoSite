## 検証環境を復活させる場合の手順

### 前提

- Shopify パートナーアカウントへのアクセス権
- 新しいデベロップメントストア（または既存ストアの再利用）
- Node.js 環境（seed スクリプト実行用）
- Shopify CLI インストール済み

### ステップ 1: 新しいストアの準備

1. [Shopify パートナーダッシュボード](https://partners.shopify.com) にログイン
2. **ストア** → **ストアを追加** → **開発用ストアを作成**
3. 任意のストア名を設定し、作成する

### ステップ 2: Theme Access トークンの取得

1. 新ストア管理画面 → **オンラインストア** → **テーマ** → **…** → **テーマアクセスを管理**
2. 開発者メールアドレスを入力してパスワードを発行
3. 発行されたパスワードをメモ（`shptka_` で始まる文字列）

### ステップ 3: Dev App のクライアントID/シークレット取得

seed スクリプトが Admin API を利用するため、Dev App の認証情報が必要です。

1. パートナーダッシュボード → **アプリ** → **アプリを作成** → **カスタムアプリ**
2. アプリ名（例：`KanpoSite Dev`）を入力して作成
3. **アプリ設定** → **クライアント認証情報** でクライアントID・シークレットを確認
4. **API アクセス** で必要なスコープを付与（Products, Pages, Blogs, Menus, Files, Metafields 等）

### ステップ 4: .env.local を更新

`env/shopify/.env.local` を開き、アーカイブ注記コメントを削除して値を更新します。

```dotenv
# Shopify 検証環境用シークレット。Do not commit.
SHOPIFY_STORE_DOMAIN=<新しいストアドメイン>.myshopify.com
SHOPIFY_STOREFRONT_ACCESS_TOKEN=<新しいトークン>
SHOPIFY_CATALOG_API_KEY=<新しいトークン>
SHOPIFY_ADMIN_ACCESS_TOKEN=
SHOPIFY_DEV_CLIENT_ID=<新しいクライアントID>
SHOPIFY_DEV_CLIENT_SECRET=<新しいクライアントシークレット>
SHOPIFY_API_VERSION=2026-04
SHOPIFY_THEME_ACCESS_DEVELOPER_NAME=<開発者名>
SHOPIFY_THEME_ACCESS_DEVELOPER_EMAIL=<開発者メール>
SHOPIFY_THEME_ACCESS_PASSWORD=<新しいTheme Accessパスワード>
SHOPIFY_CLI_THEME_TOKEN=<新しいTheme Accessパスワード>
SHOPIFY_THEME_ID=<新しいテーマID>
```

> `SHOPIFY_THEME_ID` はステップ 5 のテーマ初回アップロード後に確定します。

### ステップ 5: テーマの初回アップロード

```powershell
cd d:\Works\project\KanpoSite\web_shopify

# テーマをZIP化
shopify theme package --path .
```

Shopify管理画面 → **オンラインストア** → **テーマ** → **テーマを追加** → ZIPをアップロード。  
アップロード後に発行されたテーマIDを `.env.local` の `SHOPIFY_THEME_ID` に記入します。

または CLI を使って直接プッシュすることも可能です:

```powershell
$env:SHOPIFY_CLI_THEME_TOKEN="<Theme Accessパスワード>"
shopify theme push --store=<新ストアドメイン>.myshopify.com --allow-live
# 作成されたテーマIDを .env.local に記入
```

### ステップ 6: データの初期投入

```powershell
cd d:\Works\project\KanpoSite

# 検証環境へ seed 実行（.env.local を読み込む）
node web_shopify/scripts/seed-shopify.mjs
```

商品・コレクション・固定ページ・BLOG・メニュー・metafield定義が作成されます。

### ステップ 7: 動作確認

```
https://<新ストアドメイン>.myshopify.com
```

にアクセスしてトップページ・各ページを確認します。
