## 1. トップページ（/）

### 1.1 セクション構成

| # | セクション名 | 概要 | コンポーネント |
|---|---|---|---|
| 1 | ヒーロー | ブランドメインビジュアル + キャッチコピー + CTAボタン | `<Hero>` |
| 2 | ブランドメッセージ | 短いブランドの理念・コンセプト文（2〜3行） | `<Section>` |
| 3 | 注目商品 | ピックアップ商品 最大6点 | `<ProductCard>` × 6 |
| 4 | 畑・素材へのこだわり | 畑紹介への誘導バナー（大判写真 + テキスト） | `<FeatureBanner>` |
| 5 | ゲストハウス | ゲストハウス紹介への誘導バナー（写真 + テキスト） | `<FeatureBanner>` |
| 6 | お知らせ | 最新情報 最大5件 | `<NewsItem>` × 5 |
| 7 | SNSフィード | Instagram または Facebook フィード埋め込み | `<SocialFeed>` |
| 8 | CTA バナー | 「商品一覧を見る」への誘導ボタン | `<CtaBanner>` |

### 1.2 ヒーローセクション詳細

- **背景**: フルスクリーン画像（畑・薬草・商品のいずれか）または動画
- **テキスト**: ブランドキャッチコピー（日本語 + 英語サブコピー）
- **CTA**: 「商品を見る」ボタン → /products
- **高さ**: PC: 100vh、SP: 70vh
- **テキスト位置**: 中央揃えまたは左下寄せ
- **アニメーション**: フェードイン（テキスト・ボタン）

### 1.3 注目商品セクション詳細

- **タイトル**: 「おすすめ商品」（日本語）/ "Featured Products"（英語サブ）
- **レイアウト**: PC: 3列グリッド、SP: 1〜2列グリッド
- **商品カード**: 商品画像・商品名・カテゴリ・価格・「詳細を見る」リンク
- **データソース**: 静的データ（JSON）または Headless CMS（将来）

## 2. 商品一覧ページ（/products）

### 2.1 レイアウト

```
[ページタイトル + パンくず]
[カテゴリフィルタ（横並び or サイドバー）]
[並び替えセレクト]              [表示件数]
[商品グリッド（3列/2列/1列）]
[ページネーション]
```

### 2.2 フィルタ・並び替え

| 機能 | 詳細 |
|---|---|
| カテゴリフィルタ | 茶・チンキ・粉末・ドライハーブ・セット・その他 |
| 並び替え | 新着順・価格昇順・価格降順・人気順 |
| 表示件数 | 12件・24件・48件（PC） |

### 2.3 商品カード

| 要素 | 詳細 |
|---|---|
| サムネイル | 正方形（1:1）、hover でズームイン |
| 商品名 | 2行まで表示（以降は省略） |
| カテゴリ | バッジ表示 |
| 価格 | 税込表示（例: ¥1,980） |
| 在庫 | 在庫切れの場合グレーアウト + 「在庫切れ」バッジ |
| リンク | カード全体がリンク（/products/[slug]） |

### 2.4 SEO・メタ情報

| 要素 | 値 |
|---|---|
| `<title>` | 商品一覧 \| ブランド名 |
| `<meta description>` | 漢方・薬草商品の一覧。〇〇のこだわり〜 |
| OGP image | 商品一覧イメージ画像 |

## 3. 商品詳細ページ（/products/[slug]）

### 3.1 レイアウト

```
[パンくず]
[商品ギャラリー（左）]  [商品情報（右）]
  - メイン画像          - 商品名
  - サムネイル一覧      - カテゴリバッジ
                        - 価格（税込）
                        - 在庫状態
                        - 数量セレクタ
                        - カートに追加ボタン
                        - 配送・返品案内リンク
[商品説明タブ]
  タブ1: 商品説明
  タブ2: 成分・原材料
  タブ3: 使用方法・注意事項
[関連商品（横スクロール or グリッド）]
```

### 3.2 商品情報詳細

| 要素 | 詳細 |
|---|---|
| 商品名 | H1タグ、大きめフォント |
| 価格 | 税込表示、消費税別表示も併記 |
| 在庫状態 | 在庫あり（緑）/ 残りわずか（オレンジ）/ 在庫切れ（グレー） |
| 数量 | 1〜在庫上限まで選択可（在庫切れ時は非活性） |
| カートボタン | 在庫切れ時は「在庫切れ」表示で非活性 |

### 3.3 構造化データ（JSON-LD）

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "商品名",
  "description": "商品説明",
  "image": ["画像URL"],
  "brand": {
    "@type": "Brand",
    "name": "ブランド名"
  },
  "offers": {
    "@type": "Offer",
    "price": "価格",
    "priceCurrency": "JPY",
    "availability": "https://schema.org/InStock"
  }
}
```

### 3.4 SEO・メタ情報

| 要素 | 値 |
|---|---|
| `<title>` | {商品名} \| ブランド名 |
| `<meta description>` | {商品説明文の先頭100文字} |
| OGP image | 商品メイン画像 |

## 4. ブランド紹介ページ（/brand）

### 4.1 セクション構成

| # | セクション名 | 概要 |
|---|---|---|
| 1 | ページヒーロー | タイトル + ブランドイメージ写真 |
| 2 | ブランドメッセージ | 代表者メッセージ（顔写真 + テキスト） |
| 3 | ブランドストーリー | 創業の経緯・理念の詳細テキスト |
| 4 | こだわりポイント | アイコン + テキストで3〜5つのこだわりを列挙 |
| 5 | 沿革・タイムライン | 設立〜現在の歩み |
| 6 | メディア掲載 | 受賞・メディア露出実績（ロゴ一覧） |

### 4.2 代表メッセージセクション詳細

- 代表者写真（丸型トリミング or 自然な形）
- 名前・肩書き
- メッセージ本文（400〜600字程度）
- 署名風の手書き文字（画像）があれば使用

### 4.3 こだわりポイント

| こだわり | アイコン例 |
|---|---|
| 国産・自家栽培にこだわる | 農場のアイコン |
| 農薬不使用・有機栽培 | 葉っぱのアイコン |
| 伝統的な漢方の知恵を活かす | 薬草のアイコン |
| 少量丁寧に手作り仕上げ | 手のアイコン |
| 環境への配慮（パッケージ含む） | リサイクルアイコン |

### 6.2 Facebook 埋め込みセクション詳細

> **注意**: Facebook ページ URL は未確定のため、以下はプレースホルダー構成です。  
> 確定後に `FACEBOOK_PAGE_URL` を実際のURLに差し替えてください。

```
Facebook ページ URL（プレースホルダー）:
https://www.facebook.com/YOUR_PAGE_NAME
```

- Facebook Page Plugin（旧 Page Tab）を使用
- `<iframe>` によるタイムライン埋め込み
- 埋め込みが表示されない場合のフォールバック: 「Facebook ページで最新情報をご確認ください」リンク

#### 実装例（プレースホルダー）

```html
<!-- Facebook SDK -->
<div id="fb-root"></div>
<script async defer crossorigin="anonymous"
  src="https://connect.facebook.net/ja_JP/sdk.js#xfbml=1&version=v18.0">
</script>

<!-- Page Plugin -->
<div class="fb-page"
  data-href="https://www.facebook.com/YOUR_PAGE_NAME"
  data-tabs="timeline"
  data-width="500"
  data-height="700"
  data-small-header="false"
  data-adapt-container-width="true"
  data-hide-cover="false"
  data-show-facepile="true">
</div>
```

## 7. お問い合わせページ（/contact）

### 7.1 フォーム項目

| 項目 | 種類 | 必須 | バリデーション |
|---|---|---|---|
| お名前 | テキスト | 必須 | 1文字以上・50文字以内 |
| メールアドレス | メール | 必須 | メール形式 |
| 電話番号 | テキスト | 任意 | 数字・ハイフンのみ |
| お問い合わせ種別 | セレクト | 必須 | 商品について / 配送について / ゲストハウスについて / その他 |
| お問い合わせ内容 | テキストエリア | 必須 | 10文字以上・1000文字以内 |
| 個人情報同意 | チェックボックス | 必須 | チェック必須 |

### 7.2 送信フロー

```
1. フォーム入力
2. バリデーション（クライアントサイド）
3. reCAPTCHA v3 トークン取得
4. API Route へ POST（/api/contact）
5. サーバーサイドでメール送信（Nodemailer または SendGrid）
6. 完了メッセージ表示（ページ遷移なし or サンクスページ）
7. 自動返信メール送信
```

### 7.3 メール送信設定

- **送信先**: 管理者メールアドレス（環境変数で設定）
- **送信元**: no-reply@（ドメイン）
- **件名**: 【お問い合わせ】{種別} - {氏名}様より
- **自動返信**: お問い合わせを受け付けた旨の返信メール

## 8. 法的ページ

### 8.1 特定商取引法に基づく表記（/legal/tokusho）

必須記載事項：

| 項目 | 内容 |
|---|---|
| 事業者名 | （法人名または屋号） |
| 代表者名 | （代表者氏名） |
| 所在地 | （住所） |
| 電話番号 | （電話番号）※メール対応の場合はその旨を記載 |
| メールアドレス | （問い合わせメールアドレス） |
| 販売URL | （サイトURL） |
| 商品代金以外の料金 | 送料・消費税等 |
| 引渡し時期 | 注文後〇〇営業日以内に発送 |
| 支払方法 | クレジットカード（Visa/Mastercard/JCB等） |
| 支払時期 | 注文確定時に決済 |
| 返品・交換 | 条件・手順・期限の記載 |
| 不良品 | 商品到着後〇日以内に連絡 |

### 8.2 プライバシーポリシー（/legal/privacy）

主な記載内容：

- 収集する個人情報の種類（氏名・住所・メール等）
- 利用目的（注文処理・メール送信・アクセス解析等）
- 第三者提供の有無（決済代行会社等への提供）
- Cookieの使用（Google Analytics等）
- 個人情報の開示・訂正・削除の手続き
- お問い合わせ先

### 8.3 利用規約（/legal/terms）

主な記載内容：

- サービスの定義
- 利用に関する禁止事項
- 著作権・知的財産権
- 免責事項
- 準拠法・裁判管轄

## 9. カート・購入フロー詳細

### 9.1 カートページ（/cart）

| 要素 | 詳細 |
|---|---|
| 商品リスト | 商品画像・名前・単価・数量変更・削除ボタン |
| 小計 | 商品合計金額 |
| 送料 | 配送地域・金額（送料無料ライン表示） |
| 合計 | 税込合計金額 |
| クーポン入力 | （フェーズ2） |
| 購入手続きへ | /checkout へ遷移ボタン |
| 買い物を続ける | /products へ戻るリンク |

### 9.2 購入手続きページ（/checkout）

ステップ表示：

```
Step 1: 配送先情報入力
  - 氏名（姓・名）
  - 郵便番号（住所自動補完）
  - 都道府県・市区町村・番地・建物名
  - 電話番号
  - メールアドレス
  - 備考（任意）

Step 2: 支払い情報（Stripe / Square）
  - クレジットカード番号
  - 有効期限
  - セキュリティコード
  ※ PCI DSS 準拠のため外部決済フォームを使用

Step 3: 注文確認
  - 注文商品・配送先・金額の確認
  - 「注文を確定する」ボタン
```

### 9.3 購入完了ページ（/checkout/complete）

- 注文番号表示
- 注文内容サマリー
- 確認メール送信の案内
- 「ショッピングを続ける」ボタン

## 10. 共通UI・エラー処理

### 10.1 ローディング表示

- ページ遷移: Next.js の `loading.tsx` でスケルトン表示
- 商品一覧: スケルトンカード
- ボタン操作中: スピナー表示 + ボタン非活性

### 10.2 エラーハンドリング

| エラー種別 | 対応 |
|---|---|
| 404 | カスタム404ページ（トップへ戻るリンク） |
| 500 | エラーページ（問い合わせへの案内） |
| フォームエラー | インラインバリデーションエラーメッセージ |
| 決済エラー | エラーメッセージ + 再試行案内 |
| 在庫切れ | カートページで在庫切れ商品をハイライト |

### 10.3 404ページ

- ブランドトーンを維持したデザイン
- 「お探しのページが見つかりません」メッセージ
- トップページへのリンク
- 商品一覧へのリンク

以下の機能は現時点では実装しないが、設計・ディレクトリ構成において拡張しやすい構造を維持する。
