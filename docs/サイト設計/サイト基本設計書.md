## 3. ページ間導線

### 3.1 主要導線

```
トップ
  └─ [注目商品] ──────────────→ 商品詳細
  └─ [商品一覧を見る] ─────────→ 商品一覧 → 商品詳細
  └─ [ブランドについて] ────────→ ブランド紹介
  └─ [畑のこと] ───────────────→ 畑紹介
  └─ [ゲストハウス] ───────────→ ゲストハウス紹介

商品詳細
  └─ [カートに追加] ───────────→ カート → 購入手続き → 購入完了
  └─ [関連商品] ───────────────→ 商品詳細（別商品）

ゲストハウス紹介
  └─ [Facebook で詳細を見る] ──→ Facebook ページ（外部リンク）
  └─ [お問い合わせ] ───────────→ お問い合わせ
```

### 3.2 グローバルナビゲーション導線

全ページ共通のヘッダーナビゲーションから以下へ遷移可能：
- ロゴ → トップページ
- 商品一覧
- ブランド紹介
- 畑紹介
- ゲストハウス
- お問い合わせ
- カートアイコン（アイテム数バッジ付き）

### 3.3 フッター導線

全ページ共通フッターに以下を配置：
- 主要ページリンク（サイトマップ）
- SNSリンク（Instagram・Facebook）
- 特定商取引法に基づく表記
- プライバシーポリシー
- 利用規約
- コピーライト表記

## 4. デザイン方針

### 4.1 デザインコンセプト

**「土と草と光 ── 自然と人をつなぐ漢方の美」**

日本の山野・畑の風景から着想を得た、穏やかで信頼感のある自然派デザイン。過度な装飾を避け、素材の写真と余白が語るシンプルで上質なブランド表現を目指す。

### 4.2 参考サイト

- **Rocca dei Fiori**: https://www.roccadeifiori.eu/en/the-company/
  - 参考にする点：農場・自然素材を訴求するレイアウト、大きな写真と余白の使い方、ナチュラルトーンの配色、ブランドストーリーの語り方
  - 差別化：より日本的な間（ま）の美意識・和のテイストを加える

### 4.3 デザイン基本方針

| 項目 | 方針 |
|---|---|
| レイアウト | グリッドベース、左右対称を基本とするが余白を広く取る |
| 雰囲気 | ナチュラル・オーガニック・和モダン |
| 写真 | 畑・自然・商品の高品質写真を主役に据える |
| 文字 | 日本語は明朝系フォント（Noto Serif JP 等）、英字はセリフ系 |
| 余白 | 十分な余白（ホワイトスペース）を確保し、情報を詰め込まない |
| アニメーション | フェードイン・スクロール連動の控えめなアニメーションのみ使用 |

## 5. カラーパレット

### 5.1 基本カラー

| カラー名 | 用途 | HEX | 備考 |
|---|---|---|---|
| 白（雪白） | 背景・主要基調色 | `#FAFAF8` | 純白より僅かに温かみのある白 |
| 生成り（きなり） | セクション背景・カード背景 | `#F5F0E8` | リネン・和紙のような温かみ |
| 深緑（山の緑） | ブランドカラー・アクセント | `#2D5016` | 薬草・森・自然を象徴する深い緑 |
| 若草色 | サブアクセント・ホバー | `#5A7A2E` | 深緑の明るい補色 |
| 土色（大地） | テキスト・ボーダー | `#6B4C2A` | 大地・木の幹を想起させる茶褐色 |
| 墨黒 | メインテキスト | `#1A1A1A` | ほぼ黒だが僅かに温度を持つ色 |
| 薄墨 | サブテキスト・補足文 | `#6B6B6B` | 読みやすいグレー |

### 5.2 機能カラー

| カラー名 | 用途 | HEX |
|---|---|---|
| 購入ボタン（CTA） | カートに追加・購入ボタン | `#2D5016` |
| ホバー | ボタンホバー状態 | `#1E380E` |
| 成功 | 購入完了・フォーム送信成功 | `#4CAF50` |
| エラー | バリデーションエラー | `#C62828` |
| 警告 | 在庫わずか表示 | `#E65100` |
| リンク | テキストリンク | `#2D5016` |

### 5.3 カラー使用ルール

- 背景の主体は白・生成りの2色とし、ページ全体が重くならないよう注意する
- 深緑はアクセントとして使い、使いすぎない（ボタン・見出しアンダーライン・アイコン等）
- テキストは墨黒を基本とし、コントラスト比 4.5:1 以上を維持する
- 土色は画像の周囲・区切り線等にポイントとして使用する

## 6. タイポグラフィ方針

### 6.1 フォント選定

### 7.2 コンポーネント設計方針

- Atomic Design に準じた設計（Atoms → Molecules → Organisms → Templates → Pages）
- スタイリングは Tailwind CSS を採用（ユーティリティファーストで素早い実装）
- コンポーネントはできる限り再利用可能な形で設計し、propsで動作を切り替える
- アクセシビリティを考慮した WAI-ARIA 属性を適切に付与する

## 8. 技術構成方針

### 8.1 フロントエンド

| 技術 | バージョン（目安） | 採用理由 |
|---|---|---|
| Next.js | 14.x (App Router) | SSG/ISR/SSR対応、SEO最適化、ConoHa WING対応 |
| TypeScript | 5.x | 型安全・保守性の向上 |
| Tailwind CSS | 3.x | 高速なスタイリング・デザイン一貫性 |
| React | 18.x | Next.js に内包 |

### 8.2 ホスティング・デプロイ

| 技術 | 詳細 |
|---|---|
| ホスティング | ConoHa WING |
| デプロイ方式 | `next export`（Static Export）または Node.js SSR |
| CI/CD | GitHub Actions（ビルド・静的ファイルのFTP/SSH転送） |

### 8.3 外部サービス連携

| サービス | 用途 |
|---|---|
| Stripe / Square | 決済処理 |
| Google Maps API | 地図埋め込み |
| Google reCAPTCHA v3 | フォームスパム対策 |
| Google Analytics 4 | アクセス解析 |
| Facebook | ゲストハウスページ埋め込み・SNSリンク |
| Instagram | フィード埋め込み（検討） |

### 8.4 状態管理

- カート状態: Zustand または Context API + LocalStorage での永続化
- フォーム状態: React Hook Form + Zod（バリデーション）
- サーバー状態: SWR または React Query（フェーズ2以降のCMS連携時）

- モバイルではハンバーガーメニューを採用
