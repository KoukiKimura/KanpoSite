# Shopify管理画面でのページ作成フロー

対象テーマ: `Sansou no Megumi Shopify`

この手順は、`web_mock/` の表示構成をShopify管理画面上の操作で再現するためのワークフローです。テーマZIPをアップロードして反映済みの状態から、固定ページ、商品、コレクション、ブログ、ナビゲーションまでを登録します。

## 0. 前提

- 操作対象はPCブラウザのShopify管理画面です。
- テーマは `Sansou no Megumi Shopify` を公開、またはプレビュー対象にしておきます。
- 商品画像は事前に手元に準備します。Mockの画像を使う場合は `web_mock/public/images/` 配下を参照します。
- 本テーマは以下のShopifyデータを表示に使います。

| 種別 | Shopify上の登録先 | テーマで使う場所 |
| --- | --- | --- |
| 商品 | `Products` | 商品一覧、商品詳細、トップの注目商品 |
| コレクション | `Products > Collections` | トップの注目商品、商品一覧導線 |
| 固定ページ | `Online Store > Pages` | 古民家、お問い合わせ、FAQ |
| BLOG | `Content > Blog posts` | トップのBLOG、BLOG一覧 |
| メニュー | `Content > Menus` | ヘッダー、ドロワー、フッター |
| メタフィールド | `Settings > Metafields and metaobjects` | 商品補足情報、古民家予約URL、アクセス文 |

## 1. テーマ設定

1. Shopify管理画面で `Online Store > Themes` を開きます。
2. 反映済みテーマの `Customize` をクリックします。
3. 左下の歯車アイコン、または `Theme settings` を開きます。
4. ブランド設定を確認します。
   - ブランド名: `山草のめぐみ`
   - 英字ブランド名: `Sansou no Megumi`
   - 肩書き: `里山で養う漢方と暮らし`
   - ロゴを使う場合は `Logo` に画像を設定します。
5. 連絡先・SNSを設定します。
   - メール: 実運用の問い合わせ先
   - 電話番号: 実運用の電話番号
   - LINE / Facebook / Instagram URL: 公開するものだけ入力
6. SEO・構造化データ設定を確認します。
   - Organization名: `山草のめぐみ`
   - Organization説明: ブランド概要を120文字程度で入力
   - デフォルトOGP画像: 未設定でもテーマasset `home-hero-satoyama.webp` が使われます。正式なSNS共有画像がある場合は設定します。
   - デフォルトOGP画像alt: 画像の内容を短く入力
7. `Save` をクリックします。

## 2. メタフィールド定義を作成

先にメタフィールドを作ると、商品・ページ登録時に必要項目をそのまま入力できます。

### 2.1 商品メタフィールド

1. `Settings > Metafields and metaobjects` を開きます。
2. `Products` をクリックします。
3. `Add definition` をクリックし、以下を作成します。

| 表示名 | Namespace and key | Type | List |
| --- | --- | --- | --- |
| 内容量 | `custom.quantity` | Single line text | なし |
| 原材料 | `custom.ingredients` | Multi-line text | なし |
| 飲み方・使い方 | `custom.how_to_use` | Multi-line text | なし |
| 注意事項 | `custom.caution` | Multi-line text | なし |
| 関連商品 | `custom.related_products` | Product reference | List of values |

4. 各定義は `Pin definition` の状態にして、商品編集画面に表示されるようにします。

### 2.2 商品FAQ用のMetaobject

商品ごとのFAQを出し分ける場合に使います。初期登録を急ぐ場合は省略しても、商品ページにはテーマ側の共通FAQが表示されます。

1. `Settings > Metafields and metaobjects` を開きます。
2. `Metaobjects` で `Add definition` をクリックします。
3. 定義名を `Product FAQ` にします。
4. フィールドを追加します。

| フィールド名 | Key | Type |
| --- | --- | --- |
| 質問 | `question` | Single line text |
| 回答 | `answer` | Rich text |

5. `Save` します。
6. 再度 `Settings > Metafields and metaobjects > Products > Add definition` を開きます。
7. 以下の商品メタフィールドを追加します。

| 表示名 | Namespace and key | Type | List |
| --- | --- | --- | --- |
| FAQ | `custom.faqs` | Metaobject reference: `Product FAQ` | List of values |

### 2.3 古民家ページ用メタフィールド

1. `Settings > Metafields and metaobjects` を開きます。
2. `Pages` をクリックします。
3. `Add definition` で以下を作成します。

| 表示名 | Namespace and key | Type |
| --- | --- | --- |
| アクセス案内 | `custom.access_text` | Multi-line text |
| 予約URL | `custom.reservation_url` | URL |

## 3. 商品を登録

### 3.1 共通操作

1. `Products` を開きます。
2. `Add product` をクリックします。
3. `Title` に商品名を入力します。
4. `Description` に商品説明を入力します。
5. `Media` に商品画像を追加します。
   - 1枚目が商品詳細のメイン画像になります。
   - Mock再現では `main.webp`、`detail-01.webp`、`detail-02.webp` の順で登録します。
6. `Pricing` に税込価格を入力します。
7. `Inventory` を有効にし、在庫数を入力します。
8. `Product organization` を設定します。
   - Product type: 下表のカテゴリ
   - Vendor: `山草のめぐみ`
   - Tags: カテゴリ名と `featured` を必要に応じて追加
9. `Search engine listing` の鉛筆アイコンをクリックし、SEO title、meta description、`URL handle` を入力します。
   - seedスクリプトで投入した商品は初期SEO title / descriptionが入ります。
   - 手入力する場合は、titleは商品名 + ブランド名、descriptionは90から120文字程度を目安にします。
10. `Publishing` または `Sales channels` で `Online Store` に公開される状態にします。
11. `Theme template` は `Default product` を選択します。
12. `Metafields` に内容量、原材料、飲み方、注意事項、関連商品を入力します。
13. `Status` を `Active` にして `Save` します。

## 4. コレクションを作成

### 4.1 注目商品コレクション

トップページの `商品` セクションに実商品を表示するためのコレクションです。

1. `Products > Collections` を開きます。
2. `Create collection` をクリックします。
3. `Title` を `注目商品` にします。
4. `Description` に `トップページに表示する商品です。` と入力します。
5. `Collection type` は `Manual` を選びます。
6. `Save` します。
7. `Products` セクションで `Browse` または検索を使い、5商品を追加します。
8. 表示順を以下にします。
   1. 山のハーブブレンド
   2. 和漢の養生粉
   3. 季節の養生セット
   4. 草木の養生錠
   5. 夜のくつろぎ茶
9. `Search engine listing` でSEO title、meta description、`URL handle` を `featured-products` にします。
10. `Collection image` を設定する場合は、代表商品画像を選び、altを入力します。
11. `Sales channels` で `Online Store` を有効にして `Save` します。

### 4.2 任意のカテゴリコレクション

商品が増える前提なら、以下も作成します。

| Collection title | URL handle | 登録商品 |
| --- | --- | --- |
| お茶 | `tea` | 山のハーブブレンド、夜のくつろぎ茶 |
| 粉薬 | `powder` | 和漢の養生粉 |
| 錠剤 | `tablets` | 草木の養生錠 |
| 養生セット | `care-set` | 季節の養生セット |

各カテゴリも `Search engine listing` でSEO title、meta description、URL handleを確認します。seedスクリプトを実行した場合は、初期SEO文と代表画像altが補助投入されます。

## 5. 固定ページを作成

### 5.1 古民家ページ

1. `Online Store > Pages` を開きます。
2. `Add page` をクリックします。
3. `Title` を `古民家` にします。
4. `Content` は空でも問題ありません。本文はテーマテンプレート側のセクションで表示します。
5. `Search engine listing` でSEO title、meta description、`URL handle` を `kominka` にします。
6. `Online store` セクションの `Theme template` で `page.kominka` を選択します。
7. `Metafields` に入力します。
   - アクセス案内: 所在地、駐車場、最寄り駅からの案内を入力
   - 予約URL: 外部予約ページがある場合のみ入力
8. `Visibility` は `Visible` にします。
9. `Save` します。

### 5.2 お問い合わせページ

1. `Online Store > Pages` を開きます。
2. `Add page` をクリックします。
3. `Title` を `お問い合わせ` にします。
4. `Content` は空で問題ありません。
5. `Search engine listing` でSEO title、meta description、`URL handle` を `contact` にします。
6. `Theme template` で `page.contact` を選択します。
7. `Visibility` は `Visible` にします。
8. `Save` します。

### 5.3 FAQページ

必要に応じて作成します。

1. `Online Store > Pages` を開きます。
2. `Add page` をクリックします。
3. `Title` を `よくある質問` にします。
4. `Search engine listing` でSEO title、meta description、`URL handle` を `faq` にします。
5. `Theme template` で `page.faq` を選択します。
6. `Visibility` は `Visible` にします。
7. `Save` します。

## 6. ブログを作成

テーマのヘッダーは `/blogs/stories` へリンクする想定です。ブログのhandleを `stories` に合わせます。

### 6.1 ブログ本体

1. `Content > Blog posts` を開きます。
2. `Manage blogs` をクリックします。
3. `Add blog` をクリックします。
4. `Title` を `BLOG` にします。
5. Commentsは初期リリースでは `Comments are disabled` を選びます。
6. `Search engine listing` の鉛筆アイコンをクリックします。
7. SEO title、meta description、`URL handle` を `stories` にします。
8. `Save` します。

### 6.2 記事

1. `Content > Blog posts` を開きます。
2. `Add blog post` をクリックします。
3. `Title` と `Content` を入力します。
4. `Organization` で `Blog` を `BLOG` にします。
5. `Image` に記事のアイキャッチを追加します。
6. `Excerpt` を入力します。トップとBLOG一覧の要約になります。
7. `Tags` に `story`、`product`、`kominka` などを入れます。
8. `Search engine listing` でSEO title、meta description、URL handleを入力します。
9. アイキャッチ画像のaltを入力します。
10. `Visibility` を `Visible` にします。
11. `Save` します。

初期確認用の記事例:

| タイトル | handle | タグ | 内容 |
| --- | --- | --- | --- |
| 里山で草木を育てること | `satoyama-herbs` | `story` | 畑、季節、素材づくりの背景 |
| 朝のお茶を整える | `morning-tea-routine` | `product` | 山のハーブブレンドの飲み方 |
| 古民家で過ごす朝 | `kominka-morning` | `kominka` | 古民家滞在の雰囲気 |

### 6.3 スマホからBLOGを更新

Shopifyアプリを使うと、スマホからBLOG記事の新規作成、編集、公開、予約投稿、画像追加ができます。

事前準備:

1. iPhoneまたはAndroidにShopifyアプリをインストールします。
2. ストア `testKanpo` にログインします。
3. 更新担当者がスタッフの場合は、管理画面で `Blog posts and pages` と `Home` の権限があることを確認します。
4. 投稿用画像はスマホの写真アプリ内で正方形または横長にトリミングしておきます。

新規記事を作成する手順:

1. Shopifyアプリを開きます。
2. 画面下またはメニューの `Menu` をタップします。
3. `Content` を開き、展開アイコンから `Blog posts` をタップします。
4. `Add blog post` をタップします。
5. `Title` に記事タイトルを入力します。
6. `Content` に本文を入力します。
7. 必要に応じて `Excerpt` に一覧用の短い要約を入力します。
8. `Image` で `Add image` をタップし、スマホ内の画像をアップロードします。
9. `Organization` で以下を設定します。
   - Author: 投稿者
   - Blog: `BLOG`
   - Tags: `story`、`product`、`kominka` など
10. `Visibility` を設定します。
   - すぐ公開する場合: `Visible`
   - 下書きにする場合: `Hidden`
   - 予約公開する場合: カレンダーアイコンから日時を指定
11. `Save` またはチェックアイコンをタップします。
12. スマホブラウザで `/blogs/stories` を開き、一覧の上部に記事が表示されることを確認します。

既存記事を修正する手順:

1. Shopifyアプリで `Menu > Content > Blog posts` を開きます。
2. 修正したい記事タイトルをタップします。
3. タイトル、本文、画像、Excerpt、Tags、Visibilityを修正します。
4. `Save` またはチェックアイコンをタップします。
5. 表示確認後、必要ならスマホブラウザを再読み込みします。

画像を本文中へ追加する手順:

1. `Blog posts` で新規記事または既存記事を開きます。
2. `Content` 欄の画像アイコンをタップします。
3. 既存画像を選択、または `Add image` からアップロードします。
4. `Done` をタップします。
5. `Save` またはチェックアイコンをタップします。

スマホ更新時の運用ルール:

| 項目 | 推奨 |
| --- | --- |
| Blog | 必ず `BLOG` を選択 |
| タイトル | 20から35文字程度 |
| Excerpt | 80から120文字程度 |
| Tags | `story`、`product`、`kominka` から選択 |
| アイキャッチ画像 | 横長または正方形、暗すぎない写真 |
| SEO | title、meta description、画像altを公開前に確認 |
| 公開前確認 | `Hidden` で保存し、内容確認後に `Visible` へ変更 |
| 削除 | 原則削除せず、非公開にする |

## 7. テーマエディタでトップ・古民家・問い合わせを調整

### 7.1 トップページ

1. `Online Store > Themes > Customize` を開きます。
2. 上部のページ選択で `Home page` を選択します。
3. `Hero banner` を確認します。
   - スライド画像: `home-hero-satoyama.webp`、`home-kominka-guest-room.webp`、`home-field-walk.webp`、`home-morning-tea.webp`、商品画像
   - Overlay opacity: 20から30程度
4. `Brand intro` を確認します。
   - 農園の風景
   - 古民家の導線
   - CTAリンク: `/pages/kominka`
5. `Featured products` を開きます。
   - Collection: `注目商品`
   - Product limit: `5`
   - Show quick add: OFF
   - CTA link: `/collections/all`
6. `Latest blog` を開きます。
   - Blog: `BLOG`
   - Article limit: `3`
7. `Kominka CTA` のリンクが `/pages/kominka` になっていることを確認します。
8. `Contact CTA` のリンクが `/pages/contact` になっていることを確認します。
9. `Save` します。

### 7.1.1 商品表示とNEWバッジ

現在のテーマでは、トップページと商品一覧の商品表示を以下の方針にしています。

| 表示場所 | 表示内容 |
| --- | --- |
| トップページ | 画像、商品名のみ。PC/スマホとも2列表示 |
| 商品一覧 | 画像、商品名、価格、NEWバッジ |
| 商品詳細 | 商品説明、価格、在庫、数量、カート追加、metafields |

`NEW` バッジは以下のどちらかで表示されます。

1. 商品タグに `new` を追加する。
2. 商品が公開から60日以内である。

管理画面で任意の商品にNEWを表示する場合:

1. `Products` を開きます。
2. 対象商品を開きます。
3. `Product organization` の `Tags` に `new` を追加します。
4. `Save` します。

### 7.2 古民家ページ

1. テーマエディタ上部のページ選択で `Pages > 古民家` を開きます。
2. `Hero banner` の画像とコピーを確認します。
3. `Page kominka overview` で本文、画像、滞在スケジュールを調整します。
4. `Kominka gallery` で6枚の写真を設定します。
5. `Kominka access` でアクセス文と注意事項を確認します。
6. `Reservation CTA` の予約URLを確認します。
   - ページメタフィールド `custom.reservation_url` が入っている場合はそちらが優先されます。
   - 未入力の場合はテーマエディタ側のURL、さらに未入力ならお問い合わせ導線になります。
7. `FAQ list` を確認します。
8. `Save` します。

### 7.3 お問い合わせページ

1. テーマエディタ上部のページ選択で `Pages > お問い合わせ` を開きます。
2. `お問い合わせフォーム` セクションを開きます。
3. Lead文、補足文、電話番号表示、プライバシー同意表示を確認します。
4. 問い合わせ種別のブロックを必要数追加します。
   - 商品について
   - 古民家について
   - 取材・訪問について
   - その他
5. `Save` します。

### 7.4 問い合わせ送信後のワークフロー

このテーマのお問い合わせページはShopify標準の `{% form 'contact' %}` を使います。

1. 顧客が `/pages/contact` を開きます。
2. 以下を入力します。
   - お名前: `contact[name]`
   - メールアドレス: `contact[email]`
   - 電話番号: `contact[phone]`
   - お問い合わせ種別: `contact[お問い合わせ種別]`
   - 本文: `contact[body]`
   - プライバシーポリシー同意: `contact[プライバシーポリシー同意]`
3. 顧客が `送信する` をクリックします。
4. 未入力やメールアドレス形式エラーがある場合は、同じフォーム上にShopifyのエラーメッセージが表示されます。
5. 正常送信された場合は、同じページ上に `お問い合わせを受け付けました。` と表示されます。
6. Shopifyは問い合わせ内容をストアのSender email addressへメール送信します。
7. 運営者は受信メールを確認し、内容に応じて顧客へ返信します。
8. スパム判定された問い合わせは件名に `[SPAM]` が付く場合があります。誤判定の可能性があるため、迷惑メール振り分け先も確認します。

運用時の確認場所:

| 確認項目 | Shopify管理画面 |
| --- | --- |
| 問い合わせ受信先メール | `Settings > Notifications` のSender email address |
| ストア連絡先メール | `Settings > General` のStore email |
| 送信後メッセージ | テーマコード `sections/main-page-contact.liquid` |
| 問い合わせ種別 | テーマエディタ `Pages > お問い合わせ > お問い合わせフォーム` のブロック |

## 8. メニューを作成

### 8.1 メインメニュー

1. `Content > Menus` を開きます。
2. `Main menu` をクリックします。無ければ `Create menu` で作成し、handleを `main-menu` にします。
3. `Add menu item` で以下を追加します。

| 表示名 | Link type | リンク先 |
| --- | --- | --- |
| トップ | Home page | Home page |
| 商品 | Collections | All products、または商品用コレクション |
| 古民家 | Pages | 古民家 |
| BLOG | Blogs | BLOG |
| お問い合わせ | Pages | お問い合わせ |

4. 並び順を上表の順にします。
5. `Save menu` をクリックします。

### 8.2 フッターメニュー

1. `Content > Menus` を開きます。
2. `Footer menu` をクリックします。無ければhandleを `footer` で作成します。
3. 以下を追加します。

| 表示名 | Link type | リンク先 |
| --- | --- | --- |
| 商品 | Collections | All products、または商品用コレクション |
| 古民家 | Pages | 古民家 |
| BLOG | Blogs | BLOG |
| FAQ | Pages | よくある質問 |
| お問い合わせ | Pages | お問い合わせ |
| 配送ポリシー | Policies | Shipping policy |
| 返金ポリシー | Policies | Refund policy |
| プライバシーポリシー | Policies | Privacy policy |

4. `Save menu` をクリックします。

## 9. 法務・決済・配送の最低確認

1. `Settings > Policies` を開きます。
2. 以下を入力します。
   - Refund policy
   - Privacy policy
   - Terms of service
   - Shipping policy
   - Contact information
3. `Settings > Payments` を開き、決済手段を設定します。
4. `Settings > Shipping and delivery` を開き、送料を設定します。
5. `Settings > Taxes and duties` で税込・税設定を確認します。

| 対象 | 確認内容 |
